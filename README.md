# Qadam Courses — Онлайн курс платформасы

СӨЖ №1: веб-қызметті жобалау және REST API әзірлеу. Тақырып 13.

## MacBook Air M5 құрылғысында іске қосу

1. https://nodejs.org/en/download бетінде macOS үшін Node.js 24 немесе жаңарақ LTS орнатқышын таңдаңыз. Apple Silicon архитектурасы — ARM64. Орнатқан соң Terminal-ды қайта ашыңыз.
2. ZIP архивін Downloads ішінде ашыңыз. `course-platform` папкасы пайда болады.
3. Terminal ашып, әр команданы кезекпен орындаңыз:

```bash
cd ~/Downloads/course-platform
node -v
npm ci
npm start
```

`node -v` кемінде v24 көрсетуі керек. Папка басқа жерде болса, `cd ` теріп, папканы Terminal терезесіне сүйреп әкеліңіз де Enter басыңыз.
4. Safari немесе Chrome арқылы http://localhost:3000 ашыңыз. Terminal ашық тұрсын.
5. Тоқтату: Terminal ішінде Control+C. Қайта іске қосу: `npm start`.

SQLite серверін бөлек орнату қажет емес. Бірінші іске қосылғанда `data/platform.sqlite` жасалып, үлгі деректер енгізіледі. Кейінгі іске қосуларда өзгерістер сақталады. Node SQLite туралы эксперименттік ескерту шығарса, оның өзі сервер қатесі емес.

## Не бар

- Express 5, EJS 3, Node.js кіріктірілген SQLite.
- Student, Course, Teacher, Lesson, Enrollment, Progress ресурстарының толық CRUD API-і.
- Қосымша StudentProfile арқылы 1:1; Teacher–Course және Course–Lesson арқылы 1:M; Student–Course арасында Enrollment арқылы M:N.
- 30 CRUD операциясы және XML экспорт, прогресс қорытындысы: барлығы 32 әдіс/маршрут комбинациясы.
- Іздеу, курсқа тіркелу, сабақтың орындалуын белгілеу, барлық ресурсты басқару интерфейсі.
- Міндетті өрістер, типтер, қайталанған мәндер, сыртқы кілттер және бизнес ережелер тексеріледі.

## Беттер

| Мекенжай | Мақсаты |
|---|---|
| `/` | Каталог және іздеу |
| `/courses/1` | Курс пен сабақтар, тіркелу |
| `/learning` | Тіркелулер мен оқу прогресі |
| `/manage` | Алты ресурсты қосу, қарау, өзгерту, жою |
| `/api-docs` | API туралы қысқаша анықтама |

Бұл жергілікті оқу жобасы. Аутентификация, төлем қабылдау және бейне хостинг іске асырылмаған. Тіркелу формасында үлгі студент таңдалады; басқару беті ашық. Сервер әдепкіде тек 127.0.0.1 адресін тыңдайды.

## Тексеру

```bash
npm test
npm run test:postman
```

Тесттер уақытша бөлек база пайдаланады, жұмыс базасын өзгертпейді. Тапсыруға арналған нақты нәтижелер: `docs/TEST_RESULTS.txt`, `docs/POSTMAN_RESULTS.txt`, `docs/postman-results.json`.

Postman ішінде `docs/Qadam.postman_collection.json` файлын Import арқылы ашыңыз. Сервер жұмыс істесін. Collection Runner арқылы сұрауларды ретімен жүргізіңіз. `baseUrl` әдепкісі http://localhost:3000. Коллекция студент id=2 бар бастапқы деректерді күтеді; жасалған тест деректерін соңында жояды. OpenAPI сипаттамасы: `docs/openapi.json`.

## Құрылымы

- `server.js`: серверді іске қосу.
- `src/app.js`: Express, EJS, middleware, қателер.
- `src/service.js`: валидация, бизнес ережелер, SQL сұраулар.
- `src/db.js`, `db/schema.sql`: база, схема, бастапқы деректер.
- `routes/api.js`: REST маршруттары.
- `views/`, `public/`: HTML шаблондар, CSS, клиенттік JavaScript.
- `tests/`: API және интерфейс DOM логикасының тесттері.
- `docs/`: бес беттік есеп, диаграммалар, API, қорғау нұсқаулығы, Postman.

## GitHub немесе GitLab-қа тапсыру

Репозиторий әзірге жарияланбаған. GitHub/GitLab аккаунтыңызда бос `course-platform` репозиторийін жасаңыз. README немесе .gitignore қоспаңыз — жобада бар. Terminal ішінде:

```bash
git init
git add .
git commit -m "Add online course platform REST API"
git branch -M main
```

Одан кейін сайт көрсеткен нақты репозиторий URL-ін пайдаланып `git remote add origin ...`, содан соң `git push -u origin main` орындаңыз. Git сұраса, өз атыңыз бен email-іңізді баптаңыз; GitHub кіруін өз аккаунтыңызбен растаңыз. `node_modules` пен дерекқор `.gitignore` арқылы жарияланбайды. Ағайға репозиторий сілтемесін, есеп пен Postman нәтижелерін беріңіз.

## Қателерді шешу

- `node: command not found`: Node орнатыңыз, Terminal-ды қайта ашыңыз.
- `node:sqlite` табылмайды: Node 24+ нұсқасын қолданыңыз.
- Порт бос емес: ескі серверде Control+C немесе `PORT=3001 npm start`; браузерде 3001 портын ашыңыз.
- `ENOENT package.json`: Terminal жобаның ішінде тұрғанын тексеріңіз (`pwd`, `ls`).
- Курс жойылмайды, 409: алдымен тіркелулерін және сабақтарын жойыңыз. Тіркелуді жою оның прогресін де жояды.
