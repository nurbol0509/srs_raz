# Ағайға қорғау реті

## 1. Кіріспе — 40 секунд

«Мен 13-тақырып бойынша онлайн курс платформасын жасадым. Студент курс іздейді, тіркеледі және сабақтардың орындалуын белгілейді. Мұғалім мен курс деректерін басқаруға болады. Сервер Express, интерфейс EJS, дерекқор SQLite негізінде жасалған».

## 2. Архитектура — 1 минут

`architecture.png` көрсетіңіз. «Браузер HTTP сұрау жібереді. Express маршрутты таңдайды. Service қабаты деректерді тексеріп, параметрленген SQL арқылы SQLite-мен жұмыс істейді. API JSON немесе XML қайтарады. EJS серверде HTML құрастырады».

`server.js`, `src/app.js`, `routes/api.js` файлдарын ашып, listen, middleware, маршруттарды көрсетіңіз. Генерацияланған CRUD циклін түсіндіріңіз: әр ресурсқа бірдей бес операция тіркеледі, кесте атауы тек бекітілген тізімнен алынады.

## 3. Дерекқор — 1 минут

`er-diagram.png` пен `db/schema.sql` ашыңыз. «Негізгі алты ресурс және қосымша student_profiles кестесі бар. Student–Profile: 1:1. Teacher–Course: 1:M. Student–Course: M:N; аралық кесте enrollments. Course-де 11 атрибут бар. UNIQUE email/slug/тіркелу қайталануын шектейді; CHECK баға мен enum мәндерін тексереді; FOREIGN KEY байланысты қорғайды».

## 4. Браузердегі демонстрация — 2 минут

1. Terminal-да `npm start`, браузерде http://localhost:3000.
2. Каталогта Node деп іздеңіз, курсты ашып сабақтарды көрсетіңіз.
3. Студент Аружанды таңдап тіркеліңіз. Әли бастапқыда тіркелген — оны қайталау 409 береді.
4. Оқу бетінде бір сабақтың орындалуын белгілеңіз: пайыз өзгереді. Үш сабақтың біреуі — шамамен 33%.
5. Басқару бетінде жаңа мұғалім қосыңыз, атын өзгертіңіз, жойыңыз. Оған курс байланыстырмасаңыз, жою сәтті өтеді.
6. Серверді Control+C арқылы тоқтатып қайта қосыңыз: тіркелу/прогресс база ішінде сақталғанын көрсетіңіз.

## 5. API және қателер — 2 минут

Postman коллекциясын импорттап Runner арқылы орындаңыз. 20 сұрау мен 22 assertion бар. Әуелі `GET /api/courses`, кейін POST, PUT, DELETE сұрауларын көрсетіңіз. POST — 201; табылмаса — 404.

Үш валидация: бос міндетті өріс — 400; price жол ретінде келсе — 400; бірдей slug — 409. XML үшін `/api/courses/export.xml` ашыңыз. Content-Type application/xml екенін көрсетіңіз. Курстың сабақтары/тіркелулері барда жою 409 береді: бұл байланыс тұтастығын қорғайды.

## 6. Нәтиже — 30 секунд

«32 API операциясы, бес негізгі EJS беті, тұрақты SQLite базасы бар. Автоматты тексеруде 10 тест өтті. Postman бойынша 20 сұрау мен 22 assertion қатесіз орындалды. Бұл оқу прототипі; аутентификация мен төлем жүйесі келесі кезеңге қалады».

## Ықтимал сұрақтар

**REST деген не?** Ресурстарға URL арқылы қол жеткізу және GET/POST/PUT/DELETE әдістерінің мағынасын сақтау. Әр сұрауға қажетті ақпарат сол сұрауда беріледі.

**JSON мен XML айырмасы?** JSON объект пен массив түрінде, XML тегтер арқылы беріледі. Екеуі де дерек тасымалдау пішімі. Бұл жобада бір SQLite дерегі екі пішімде шығарылады.

**EJS не үшін?** Сервердегі деректі HTML шаблонға енгізеді. `<%= ... %>` HTML таңбаларын escape етеді.

**PUT пен POST айырмасы?** POST жаңа жазба жасайды. PUT нақты id жазбасын барлық міндетті кіріс өрістерімен жаңартады.

**Неге SQLite?** Оқу жобасына бөлек сервер қажет етпейді, файлда сақталады, SQL мен байланысты шектеулерді қолдайды. Үлкен көппайдаланушылы өндірістік жүйеге PostgreSQL сияқты база қарастырылуы мүмкін.

**Прогресс қалай есептеледі?** Орындалған сабақ саны / курстағы барлық сабақ саны × 100. Сабақ жоқ болса, 0. Басқа курстың сабағын сол тіркелуге белгілеуге болмайды.

**SQL injection қалай шектеледі?** Пайдаланушы мәндері SQL ішіне тікелей біріктірілмейді, prepared statement параметрлерімен беріледі; кесте атаулары allowlist арқылы алынады.

**Тесттер не тексерді?** CRUD, қайта іске қосқанда сақталу, JSON/XML, валидация, FK, прогресс ережелері, escape және басқару формасының DOM әрекеттері. Браузердің нақты визуалды көрінісі бұл ортада тексерілмеді.
